# Dimotek

Sitio de marketing de **Dimotek**, agencia de systems integration y AI engineering.

## Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **UI & Estilos:** [React 19](https://react.dev/), [Tailwind CSS v4](https://tailwindcss.com/), [shadcn/ui](https://ui.shadcn.com/)
- **Lenguaje:** [TypeScript](https://www.typescriptlang.org/)

## Inicio rápido

Instalar dependencias y levantar el servidor de desarrollo:

```bash
npm install
npm run dev
# o
pnpm install
pnpm dev
# o
yarn
yarn dev
```

Abrí [http://localhost:3000](http://localhost:3000) en el navegador para ver el sitio.
